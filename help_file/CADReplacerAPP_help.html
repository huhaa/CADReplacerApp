CAD文字批量替换工具 帮助文档

作者：DHB 版本：V2.0 更新日期：2026年06月04日

界面概览

V2.0 全新重构，采用左右分栏布局：左侧为替换规则列表，右侧为待处理文件列表，操作更加直观高效。

核心功能

支持对以下文字类型进行批量查找替换：

  • 普通文字 — 单行文字 (AcDbText)
  • 多行文字 — 多行文字 (AcDbMText)
  • 块属性 — 块引用中的属性文字 (AcDbAttribute)
  • 嵌套块 — 递归处理嵌套块内的文字
  • 布局 — 同时处理图纸空间（布局）中的文字
✅ V2.0 新增：支持正则表达式匹配、区分大小写开关
✅ V2.0 新增：撤销上次替换操作
✅ V2.0 新增：处理中可随时取消

操作步骤

1. 添加替换规则 — 在「查找」输入框输入原始文字，在「替换」输入框输入目标文字。可选勾选「正则」启用正则表达式匹配，勾选「大小写」区分大小写。点击「添加规则」按钮。

2. 选择替换范围 — 根据需要勾选要处理的文字类型：普通文字、多行文字、块属性、嵌套块、布局。默认全部勾选。

3. 添加文件 — 点击右侧「添加文件」按钮选择 DWG 图纸，支持多选。可点击「删除选中文件」移除不需要的文件。

4. 统计（可选） — 点击「统计」按钮可预览当前规则和文件数量，确认无误后再处理。

5. 开始替换 — 点击「🚀 开始替换」按钮启动批量处理。处理过程中按钮变为红色「⏹ 取消」，可随时点击取消。

6. 撤销（可选） — 替换完成后如需恢复，点击「↩ 撤销上次」按钮可将文件还原。

注意事项

⚠️ 重要提示：

  1. 批量替换依赖 AutoCAD COM 接口，处理前请确保 AutoCAD 已安装并可正常打开
  2. 处理过程中请勿手动操作 AutoCAD，避免 COM 冲突
  3. 每个文件替换完成后会自动保存，处理前建议备份原文件
  4. 执行完成后请检查 error.log 日志文件，确认是否有处理失败的文件
  5. 如有文件处理失败（红色标记），可尝试重新执行替换操作
  6. 部分失败可能是 AutoCAD 启动较慢导致，建议替换前先手动打开 AutoCAD
  7. 撤销功能仅对最近一次替换操作有效，关闭程序后无法撤销

快捷操作

  • 多选规则/文件 — 按住 Ctrl 或 Shift 点击可多选，方便批量删除
  • 连续失败保护 — 连续3个文件处理失败时会弹窗询问是否继续
  • 配置记忆 — 替换规则和文件列表会自动保存，下次启动时恢复
